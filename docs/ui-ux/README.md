# UI/UX modernization handoff

Start here:

- [Baseline audit](BASELINE_AUDIT.md) — what existed before the redesign.
- [Design system](DESIGN_SYSTEM.md) — tokens, typography, spacing, components, interaction states.
- [Component inventory](COMPONENT_INVENTORY.md) — current file and responsibility map.
- [Implementation plan](IMPLEMENTATION_PLAN.md) — stages, decisions, deviations, rollback.
- [Screen specifications](SCREEN_SPECIFICATIONS.md) — behavior of every screen.
- [Responsive audit](RESPONSIVE_AUDIT.md) — tested widths and overflow results.
- [Accessibility audit](ACCESSIBILITY_AUDIT.md) — axe, keyboard, contrast, and remaining gaps.
- [Test plan](TEST_PLAN.md) — scope and commands.
- [Test results](TEST_RESULTS.md) — actual commands, results, and evidence.
- [Regression report](REGRESSION_REPORT.md) — compatibility, intentional changes, known issues.
- [Final handoff](FINAL_HANDOFF.md) — summary, file changes, deployment, next steps.

Final screenshots are in [screenshots](screenshots/).

The frontend is the Git repository; the workspace root is not. No backend source, schema, authentication, calculation, or workbook-template changes are part of this work.
